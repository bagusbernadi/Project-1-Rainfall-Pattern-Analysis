    Batasan yang sudah diketahui

    • Pola belum tentu penyebab. Analisis ini tidak menguji sebab-akibat.
    • Akurasi bisa menyesatkan. Hari hujan jauh lebih sedikit dari hari tidak hujan, jadi baca bersama recall dan proporsi hari bertanda peringatan.
    • Hari berdekatan saling terkait. Baris tidak sepenuhnya independen, hasil dilaporkan sebagai pola, bukan uji statistik.
    • Cakupan tidak merata. Periode dan kolom terisi berbeda antar lokasi. Data berakhir Juni 2017.
    • Zona iklim dibuat manual (usulan awal) di data/dim_location.csv.
